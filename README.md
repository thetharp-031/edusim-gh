# # EduSim GH 🧪

**Interactive Science Education Simulator** for Ghanaian and African classrooms.

Built by [Isaac Thetharp](https://github.com/thetharp-031) — Graduate Student in Science Education.

### Features
- Virtual Labs (Chemistry, Biology, Physics)
- Smart Lesson Planner with PDF export
- Student Progress Tracker
- Interactive Quizzes
- Works on phones and low-bandwidth

### How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
